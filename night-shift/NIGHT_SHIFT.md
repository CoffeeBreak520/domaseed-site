# DOMASEED GEO 夜班规则 v1

## 授权与边界

仅在启动器指定的 `night/geo-YYYYMMDD` 分支工作。禁止合并 main、发布、改 DNS / GitHub Pages / 仓库设置、付费、对外发送。唯一发送例外是本任务明确授权的 Git night 分支推送。仓库是公开仓库，分支上的报告也可公开访问；禁止写入姓名、个人信息、凭据、内部项目资料。

本次只搭系统。站点正文、HTML、meta、schema、robots、sitemap、CNAME 全部只读。可修问题仅输出到 `night-shift/drafts/`，等待以后单独批准。所有写入仅限 `night-shift/`；原始运行日志和预览副本放 `night-shift/logs/`，不提交。不得修改启动器、规则、安装器或测试来绕过边界。

## 一次只领一个任务

1. 先读 TASK_QUEUE.md 顶部“创始人决定”。决定只能补充本范围；超范围要求标 NEEDS_FOUNDER，不能自行扩权。创始人明确把任务状态改回 TODO 才能重领。
2. 只执行文件里第一个 `状态: TODO` 的任务；启动器指定的 ID 必须与之相同。每次全新 Codex 会话只执行这一项。
3. 每个验收项首次尝试后最多重试 2 次。将每次失败和次数写进 evidence 中该任务的记录，跨会话不能清零。超限标 BLOCKED。
4. 验收完成改 DONE；技术或依赖失败改 BLOCKED；需要创始人判断改 NEEDS_FOUNDER。写一行结果、证据路径，并更新当晚报告。发现问题并完成审计可算 DONE，但必须区分“检查完成”和“网站问题已解决”。
5. 需要创始人时，把按优先级排列的问题和选项写到报告“待我决定”，标记 NEEDS_FOUNDER，然后结束本次会话，不等待回复。启动器可继续其他独立 TODO。
6. 不得伪造验证。DONE 必须引用实际存在的 `night-shift/evidence/` 文件，包含命令、时间、退出码、检查结果。原始 logs 不作为唯一证据。AI可见度的实际回答不能由当前模型自问自答代替；网页检索不能冒充 ChatGPT、Gemini 等的真实回答。

## 定位与来源

DOMASEED 对外定位为“教育游戏”，目前开发中。不得写创始人姓名或照片，不做学习效果承诺，不把规划当成已实现。GEO-002 只做只读检索；没有联网或真实回答渠道必须 BLOCKED。旧研究不能冒充当晚基线。GEO-003 必须依赖 GEO-002 DONE，草稿只存 drafts。

## 结束协议

更新本任务状态和结果，保留其他任务、创始人决定和既有报告。报告使用四个固定标题。尝试提交并仅推送指定 night 分支；沙盒若禁止 Git 元数据或网络，记录失败，交由外层启动器完成，不申请审批或提升权限，不重做任务。

最终回答严格为 JSON 对象（不要代码围栏）：

`{"task_id":"GEO-001","status":"DONE|BLOCKED|NEEDS_FOUNDER","summary":"真实结论","evidence":["night-shift/evidence/真实文件路径"]}`

状态必须与队列一致。缺少证据的 DONE 会被启动器降为 BLOCKED。进程启动失败、超时、原地不前进都会生成 BLOCKED 记录，不无限重试。
## 主机桌面预检

由 PowerShell 启动器在领取任务前完成，不由模型执行。只关闭当前用户/会话、已验证 OpenAI.Codex 安装目录内进程与其 Swift sidecar；不结束 Codex CLI 或沙盒服务。先正常请求关闭，共等待最多60秒，再强制结束仍存活的目标。实际探测运行时 DLL 的独占读取/权限元数据访问，不修改文件或 ACL。释放验证失败则当晚跳过，队列保持原状态，记录占用信息、提交报告后退出。无论成功失败均不重新打开桌面应用。安装前要求原流程与真实桌面开启状态下两次试跑均通过。
